# S0-04：本地密码认证与持久会话核心

2026-11-10。本步只交付服务层与结构迁移，未提供 HTTP 登录入口。

## 实现

- 0003 创建独立凭据与会话表，不为既有用户设默认密码。
- 密码使用随机 16 字节盐与 PBKDF2-HMAC-SHA256，600000 次迭代；参数参考 OWASP https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html 。当前采用 Python 标准库以减少本地阶段依赖，算法标识随哈希保存，后续可设计迁移。
- 随机会话令牌使用 32 字节随机源，数据库仅存 SHA-256 摘要。会话有效期暂定八小时，UTC 存储；退出通过删除记录撤销。
- 每次会话认证检查用户是否启用，不将角色或可见账户写入会话快照。未知用户与错误密码使用统一错误，未知用户也执行密码哈希验证。
- 函数只使用调用方连接，不自行提交事务。认证成功的用户 ID 才能用于 visible_accounts；HTTP 请求不得自行指定身份。

## 验证

11 项测试通过。新增测试覆盖随机盐、错误密码、损坏哈希、密码长度、未知用户、成功会话、令牌不明文入库、伪造令牌、退出幂等、过期、停用用户拒绝登录及既有会话。MySQL 迁移可重复执行，现有权限与健康检查回归通过。Ruff lint、格式、mypy strict 通过；已有 TestClient 弃用提示仍在。

合成用户与会话在测试事务中回滚，不留下默认业务账号。新代码文件头及关键流程均有中文说明。

## 后续与边界

本地账号密码为当前实现路径，尚未排除未来企业 SSO 接入。八小时有效期与密码长度是当前本地默认，正式策略需部署前评估。

下一步接入 HTTP 登录/退出/当前用户与按请求新事务，验证跨连接提交后身份和权限变更生效；同时补充 Cookie、CSRF、登录失败限速及认证审计。当前尚无账号创建/改密、会话清理、重置密码后全会话失效和管理审计接口，不向公网开放本服务。

0003 降级删除全部认证数据，执行前需备份并明确会话失效影响。本步没有执行破坏性降级或线上操作，代码通过 Git 检查点保留。
