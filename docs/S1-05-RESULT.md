# S1-05：只读文件导入预览

2026-11-10。按用户要求保留原始业务语义，同时优化批量排错体验：一次检查多行并返回问题清单，而非首错即停止。本步没有网页上传或正式导入按钮。

## 使用

项目根目录执行（PowerShell）：

```powershell
$env:PYTHONPATH='src'
uv run --locked python -m dashboard.import_preview --input docs/example-keywords.json --mapping docs/example-account-mapping.json
```

两份 example JSON 是纯合成文件，映射中的 ID 1 仅作格式演示，不代表库中存在该投放账户。示例预期 1 行、0 问题、校验合计 12.3400；write_allowed 始终 false。

实际文件替换 --input，显式账户映射替换 --mapping。支持 UTF-8/BOM 的 CSV 或 JSON 行对象数组；映射必须为 JSON 对象“源账户名→内部账户正整数 ID”，不使用凭据。CSV 表头与 KeywordRow 字段完全一致，所有原字段必填。

## 预览行为

- 每文件最多 5 MiB，每次最多 1000 行。CSV 非负整数字段显式解析，非法值保留给严格校验拒绝；重复表头、缺列/多列、列数不一致不静默接受。
- JSON 数字小数用 Decimal 解析；拒绝重复对象键和 NaN/Infinity，不从文件内容自动推断金额原始来源。旧 SQLite 浮点导出的十进制字符串不因此变成已验证金额。
- 逐行汇总重复键（含首次出现行号）、缺少账户映射、非法记录（包含已知出错字段）。记录行号指数据记录顺序，CSV 多行单元格时不等于物理文件行号。
- valid_unique_rows 和 validated_cost_total 仅统计通过校验的唯一行，不能据此导入部分错误批次。无行文件不视为有效批次。
- 复用写入前置校验，避免设备长度、金额来源等预览通过但存储校验失败。此共用校验不执行数据库操作。
- 报告不包含账户值、词文本、原始行、密码或任意未知列名。结构/编码错误统一脱敏，不输出底层解析异常。退出码 0=文件校验通过，1=行问题或空文件，2=文件/映射/格式错误。

## 实际验证

18 项相关测试通过，包含文件预览、既有输入校验、真实 MySQL 幂等写入和数据库迁移边界。示例命令实际运行，确认 preview_only、structure_valid=true、database_checked=false、write_allowed=false。Ruff lint、格式和 mypy strict 通过。

新增模块和测试有中文文件头与关键说明。测试覆盖 CSV/BOM、JSON 十进制、重复键、多行错误、空文件、超行数、存储长度及 CLI 输出脱敏。未声称运行完整既有套件，已知测试隔离问题仍按待修清单处理。

## 下一步与限制

当前只检查文件内容和映射格式，不验证数据库账户存在性、权限、库内新增/覆盖数量或历史快照冲突；报告明确 database_checked=false。金额来源未核实，不能把退出码 0 理解为正式导入许可。

下一步添加受控的数据库只读对比预览，展示新增/覆盖/未变化/缺失账户；之后才设计确认写入。当前没有写库开关、文件上传、生产访问或真实导入，页面不变。回退只撤销本次代码，无业务数据恢复操作。
