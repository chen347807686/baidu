# S1-09 关键词每日表现只读接口

## 范围与契约

新增 GET /api/v1/reports/keywords/daily，必须登录，参数 start/end/keyword
必填，account 可选。使用正式日报，按完整关键词精确匹配，不修剪词文本，
保留正式列二进制比较语义。所选范围最多连续 366 天，超出返回 422。

账户范围先于聚合过滤，显式无权账户返回 403；查询和身份验证在同一
REPEATABLE READ 事务中完成。按日期升序返回，最多 366 行，不返回账户内部
明细或无权词；同词跨可见账户、设备和关键词 ID 在当天合计，沿用列表粒度。
原始指标先相加再计算比率，未知 conv_78/92 保留，不加入综合线索。

响应包含 keyword/start/end/account、固定正式来源与 missing_dates=omitted。
没有记录的日期不补零，无记录返回 rows=[]，不把缺失采集解释为零投放。
接口使用显式 Pydantic 响应模型并禁止缓存，不修改现有列表默认行为。

## 验证

隔离 MySQL 用合成数据验证多设备合计、无权账户排除、指定账户拒绝、
不同日期分组与升序、缺失日期省略、零分母、空结果及日期范围拒绝。
HTTP 验证未登录 401、登录后返回正式空结果、禁止缓存、无权账户 403
与倒置日期 422。完整测试 96 项通过，Ruff、格式和 mypy strict 通过。

## 限制、回退与下一步

本步仅交付接口，页面尚未增加入口；没有运行库导入、迁移或百度调用。
长 TEXT 关键词的精确查询性能仍需代表性数据评估，不因日期有界宣称查询成本
固定。回退本提交即可移除路由与模型，不涉及数据回退。下一步将每日明细
接到现有关键词列表，保留筛选上下文、加载失败和过期请求保护。
