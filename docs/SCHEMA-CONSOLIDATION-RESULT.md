## 漂移验证

隔离 MySQL 从空库执行冻结迁移，然后针对七张表：

- Alembic 比较列类型、可空性、外键、默认值与索引；MySQL BOOL/TINYINT(1) 仅允许已知等价类型。
- 单独核对主键列及顺序、显式 collation、现有 CHECK 名称及表达式。
- CHECK 比较仅规范当前 AND/IN 表达式的反射包装，未来引入 OR 时测试会要求升级比较方式，避免忽略括号语义。
- 修改模型副本的金额精度，确认漂移检查确实产生差异；不修改实际库或全局模型。

本次测试不代表已检查所有认证/计划表、库级默认排序规则或触发器。role collation 仍按旧结构继承，不将模型集中当作该安全问题已修复。
