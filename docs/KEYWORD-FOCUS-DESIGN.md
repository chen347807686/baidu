## 1. 原项目可参考的思路

源码路径均相对旧工程 `onetitle2-dashboard/`；仅阅读相关源码，未调用旧连接入口或读取凭据。

| 原实现依据 | 可参考之处 | 新需求需要调整之处 |
|---|---|---|
| `keyword_monitor/expansion.py:list_seeds` | 从关键词/搜索词表现中选有转化种子，保存消耗、点击、线索及观察日期 | 有转化是优质判断证据，不是唯一条件；首批先用已获取关键词，搜索词接入单独核实 |
| `keyword_research/quality.py:score_keyword` | 质量分、等级、问题和建议分开展示；无 API 数据时采用意图、可行性等维度 | 旧行业词库、合规假设和评分阈值不能直接通用；原词真实表现与新词预测质量要区分 |
| `keyword_monitor/expansion.py:create_run/run_expansion` | 保存任务、种子快照、进度、候选及失败信息 | 实际调用 `KRService/getKRByQuery`，属于百度推荐，不是大模型生成；旧 Web 内守护线程不适合作为新持久执行机制 |
| `keyword_monitor/expansion.py:_candidate_from_item` | 候选保留 `seed_word/seed_source/seed_leads`，展示和导出可追溯 | 旧候选按词去重后只保留一个种子；新版去重需独立保留全部来源关系 |
| `keyword_monitor/expansion.py:list_candidates/update_candidates_status/export_candidates` | 分页筛选、待审核/采纳/忽略、单条/批量处理、CSV/Excel | 审核状态与否词状态独立；展示原词和否词原因；不能以“忽略”替代否词标注 |
| `relevance_screen/screen.py:run`、`llm.py:classify_batch` | 账户业务画像、规则先行、模型补充、相关/不相关/边界及理由 | 旧模型用于相关性分类，不是大模型拓词；业务相关不能直接推导为优质 |
| `relevance_screen/negatives.py:match_word/match_words` | 精确/包含匹配、词类型范围及上传词库解析 | 命中必须带账户、适用范围及匹配依据；模型建议与人工确认分开 |

## 2. 建议的最小工作台

主入口“关键词工作台”，包含“原关键词”“拓词结果”“任务记录”。报表与账户作为辅助入口，其他未实施功能后置。原词表保留账户、表现、质量及理由、否词状态；结果表固定展示拓展词、全部来源原词、批次、理由与否词状态。

建议按钮：判断质量、标为优质、标注否词、取消人工标记、大模型拓词、查看原词、采纳、忽略、导出。先单条与有边界的批量操作，明确“当前页选中”范围，不能隐式处理全部筛选结果。质量参数未冻结前不展示为可靠默认结论。

## 3. 数据与执行建议

沿用现有 MySQL、FastAPI、账户权限及迁移机制。原词以账户和稳定对象身份关联，文本作为快照；同文多对象及搜索词应保留来源身份，不使用跨账户文本全局唯一键。

建议补充原词判定记录、任务/种子快照、候选、候选与种子多对多关系及追加审计；具体字段和索引在 K2 前单独设计。质量判断记录观察窗口、证据、规则版本；模型记录提供方、模型、提示词版本、请求批次和逐种子结果。原始业务词和完整模型响应不写普通日志。

模型输入包括选中优质原词及受控业务/地域/否词约束，明确仅将关键词作为数据。每项输出引用服务端分配的种子 ID、拓展词及理由；服务端验证 ID 属于本任务、结构与长度符合约束，再检查重复及否词。生成失败、空结果和部分成功分别显示，不用虚构词补齐数量。多个原词生成同词时合并展示并保存所有关联。

任务持久化后由独立 worker 领取，有超时、租约、逐项进度和重试幂等。模型请求不持有数据库长事务；重试不能重复产生候选或覆盖人工决定。读取与提交均校验可见账户，任务或来源明细不得绕过权限。

否词仅标注和审核；是否实际添加百度否词属于另一动作，继续适用预览、确认、读回及审计，不随标注执行。人工确认优先，自动重跑保留原决定；有转化、边界或互相冲突证据明确提示复核。

## 4. 实施前需落实的参数

- 优质词观察窗口、最低样本、线索成本/转化参考阈值，以及缺少表现数据时的处理；先给样例和推荐，不写成已确认。
- 模型提供方/型号、每词生成数量、单批上限、费用和超时预算；不复制旧凭据。
- 否词在账户/计划/单元与词类型上的匹配范围、人工标注和撤销规则。

自动拉数、真实旧库导入、百度写操作和完整大平台数据结构均不是本次文档小步的已实现能力。
