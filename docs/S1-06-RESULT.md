# S1-06：数据库只读对比预览

2026-11-10。本步在文件预览基础上增加显式 --database 模式，仍无任何确认入库或写入开关。

## 使用

默认命令仍只检查文件；附加 --database 时，按 ONETITLE_DB_* 注入的本机应用数据库配置读取正式表。命令限制目标为 127.0.0.1:13306/onetitle_v2_local，避免误连远端；配置缺失或目标不符则失败，不输出参数值。测试服务函数使用独立随机测试库验证。

```powershell
$env:PYTHONPATH='src'
uv run --locked python -m dashboard.import_preview --input docs/example-keywords.json --mapping docs/example-account-mapping.json --database
```

运行前需由本地受限配置注入应用账号；不要把数据库密码写入参数、文档或 Git。示例映射 ID 1 只是格式占位，不代表真实账户存在。当前运行库无投放账户，因此示例的数据库预览应报告账户缺失。

## 分类与输出

- new：账户存在，该完整日事实主键未入库。
- changed：主键相同，持久字段有变化；只输出字段名，不输出旧值/新值。
- unchanged：主键与全部持久字段相同；Decimal 按数值比较，不将补零当作变化。
- missing_account：映射目标账户不存在，不推断自动建账户。
- account_alias_review：相同内部账户已有不同源 user_name，单独标记待核对，不决定是否改名合并。账户级名称变化可能跨日期影响对账，因此即使当前候选键不存在也先提示核对。

返回原输入顺序行号和各分类计数，无账户名、词文本或原值。文件校验未通过则完全跳过数据库连接；候选再次使用写入前置校验。数据库核对以 REPEATABLE READ 只读事务进行，主键按最多一百项分批查询，所有读取来自同一快照。结果不锁定后续数据，执行前仍须复核，不能直接拿旧预览作为写入授权。

write_allowed 始终 false。缺失账户或名称需核对时命令返回 1；连接、配置或数据库错误返回 2；文件和数据库对比无此类阻碍时返回 0。0 仅代表这两层校验完成，不表示金额来源、权限审批、备份恢复或正式导入条件已满足。

此工具属于本机受控维护入口，没有 Web 端授权界面，不能提供给普通用户绕过账户权限读取数据库；未开放 HTTP 上传或导入接口。
