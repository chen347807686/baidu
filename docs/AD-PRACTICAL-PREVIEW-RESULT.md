# 投放导入的实用预览层

新增 preview_ad_rows，在严格 ad_input 前统一处理常见表格格式，避免每个对接方
重复编写相同转换。该入口仅准备和预览，不写数据库，不自动部分提交。

- 数字字符串与安全范围内的整数浮点转为整数；超过浮点安全整数范围的 ID 拒绝。
- ISO/斜杠日期、带时间的日期及 datetime 可取其本地业务日期，不先转 UTC 截日。
- ISO 时间文本解析；无时区时间仅在显式配置来源固定时区时解释，并记录警告。
- 显式 summary 范围的空串/all/全部/汇总设备标识转为 None，不猜测其他设备。
- 不适用的可选 ID/文本漏列可补 None；指标、来源身份和来源时间不自动造值。
- 浮点金额默认拒绝，allow_float_cost=True 时按 repr 转 Decimal 并标记
  float_cost_requires_review；仍拒绝超精度，不自动舍入，不宣称原金额无损。

返回 valid_rows（原行号、清洗后的规范行）、errors、warnings；逐行收集问题，
重复事实报告原行号，整个批次无需为了寻找下一个错误反复导入。调用方可展示
有效/失败条数，再让维护者决定修正全部或明确选择可用行。不可把预览结果当作
已经提交，也不能未经确认把失败行忽略后宣称整批成功。

警告/错误只含固定字段与代码，不复制数据值。返回规范字典用于后续写入入口
重新严格校验；浮点转换后的警告仍需调用方保留并确认，当前无公共写入 UI，
也没有自动确认逻辑。固定时区参数适合无夏令时来源，其他来源需显式带时区。

暂保留 v1 扁平维度与稳定指纹，不自动将任意嵌套 JSON 塞入身份维度。真实来源
的嵌套结构应先核对哪些字段是身份、哪些是展示或状态，再版本化适配；不能为
图方便把可变名称或整份响应纳入事实键。百万/千万行性能没有实测证据，本步
不声称哈希是瓶颈或已优化；现阶段每次最多一千行准备，性能验证单独推进。

新增四项回归覆盖常见格式、原输入不变、坏行汇总/有效行保留、浮点/时区策略、
大整数与未知设备拒绝；连同严格输入测试 23 项通过。全部非数据库测试通过，
数据库测试明确跳过；本步未修改数据库与写入服务。规范、格式和类型检查通过。
尚未接网页/文件读取界面，下一步接统一文件预览输出，继续优先减少实际操作步骤。
内部数据库说明和设计及本地计划变动仍不上传。
