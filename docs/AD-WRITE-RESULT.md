# 统一投放事实受控写入

新增后台 store_ad_batch(engine, rows, expected_versions)，接收规范原始行，
再次通过 prepare_ad_rows 计算指纹，不信任调用方自造 PreparedAd。最多十行
事实，自管事务；空批且空版本映射不连接数据库。未提供网页或文件写入入口。

expected_versions 必须精确覆盖本批来源 ID，且为严格正整数版本。按固定次序
锁定内部账户、来源映射，再读取已有事实；验证绑定、启用状态与版本。不存在
账户/映射、停用或版本改变均拒绝。后续其他写入入口也必须遵守账户→来源的
锁顺序，不能绕开本服务。现有来源改名仅锁来源，不同时反向获取账户锁。

新事实插入；同键先比较完整 dimensions、grain_version 和 source_account_id，
阻止维度指纹碰撞或不同来源交叉覆盖。以 source_checked_at 判定新旧，不按
来源 revision 字符串排序。旧核验拒绝；相同核验时间只有相同内容指纹和修订
才视为重复；新核验全量覆盖，NULL 也覆盖旧值。名称、指标更正不累加。
此顺序依赖来源提供真实可靠核验时刻，不能用接收时间伪装来源新鲜度。

映射及事实检查失败向外传播，使先写成功行随整个事务回滚。数据库错误只记录
脱敏类别/码，返回安全 AdWriteError；连接中断不能证明提交失败，必须按完整
事实键读回核对后决定重试。返回 inserted/updated/unchanged 是已提交服务结果，
新核验即使业务内容不变也更新核验元数据并计 updated。

隔离 MySQL 验证首次写入、重复幂等、改名/计数覆盖、NULL 覆盖、旧核验拒绝、
同刻内容冲突、版本失配、停用、十行上限及后行拒绝导致前行回滚。
完整测试 123 项通过，Ruff、格式、mypy strict 通过，无新增迁移或运行库改动。

限制：十行上限仅约束本服务实际事实 DML；尚无 outbox、水位、审计联合提交，
加入后须重新分配总事务预算。不宣称满足一秒写入截止时间，无自动重试。
混合报表/设备行可以保存，后续查询不能混加；NULL 聚合完整性由查询服务处理。
不删除刷新窗口缺行，不发布投影。下一步文件只读预览/对比新模型，再设计确认
入口及提交结果核对；内部数据库说明及设计文档继续仅保留本地。
