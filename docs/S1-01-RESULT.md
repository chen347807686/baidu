# S1-01：合成关键词报表接口

2026-11-10。本步仅验证首条数据查询链路，没有报表页面，不读取旧数据库或接入百度。

## 完成范围

0006 创建 report_sample_daily，明确为合成样本结构，不作为真实采集事实表。真实唯一粒度、转换字段原值、人员归属及分类映射须后续核对，不可直接向此表导入生产日报。

GET /api/v1/reports/keywords 需现有登录 Cookie；接口标记 data_source=synthetic。支持起止日期、account 整数 ID、search、sort(cost/click/keyword)、order、page 和 page_size(1–200)。默认昨天结束七天，按 UTC+8 当前日期确定。日期单端、倒置及非法分页/排序返回 422，无登录 401，明确请求无权账户 403。

先通过既有统一权限查询选取账户 ID，再在 SQL 内进行日期、账户和字面搜索过滤、按关键词文本聚合、稳定排序和 LIMIT/OFFSET。显式选择单列用于 IN，不修改原 visible_accounts 双列契约。关键词使用 utf8mb4_0900_bin；同值使用关键词次序打破平局。当前排序字段均非空，不提供派生空指标排序。

响应含 rows、total、summary、page、page_size、applied_filters。total 是过滤后关键词组数，summary 是整个筛选结果，不是当前页合计。请求以 REPEATABLE READ 新事务查询权限、总数和数据，单请求快照一致；不承诺两次分页请求跨数据变化仍无重叠。

消耗以 DECIMAL(18,4) 保存和字符串传输，计数相加后计算综合线索、咨询量、线索成本、咨询率、线索率及 CPC；零分母为 null。合成契约暂用 ROUND_HALF_EVEN，不代表真实金额来源已无损核实。本步没有计划列表、人员/部门/分类筛选、关键词历史、导出或真实数据采集，不能当作旧报表完整替代。
