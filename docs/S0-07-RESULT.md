# S0-07：本地登录页面

2026-11-10。本步以同源静态 HTML/CSS/JavaScript 验证认证链路，不引入完整业务前端工程，也不代表 Vue 等核心界面方案已冻结。

## 完成内容

显式开启认证后，根路径提供中文登录页。包含账号密码输入、正在登录、错误密码/停用、限速、网络失败重试、登录后可见账户列表、空账户和退出状态。密码提交结束后清空，不写入 localStorage/sessionStorage；令牌由 HttpOnly Cookie 管理，脚本不读取令牌。账户名称通过 textContent 输出，无内联事件。

页面设置同源 CSP、禁止框架嵌入、no-store、nosniff 与 no-referrer；脚本和样式在 /assets 提供。异步操作串行执行，操作中禁用按钮，网络结果不确定时先重查服务端会话。浏览器支持要求包含 fetch、AbortSignal.timeout；旧浏览器兼容性后续随目标环境确定。

## 验证

13 项自动测试及 Ruff lint、格式、mypy strict 通过。HTTP 集成新增页面、脚本、样式与 CSP 验证，认证流程原有回归通过。

实际浏览器在本机 8082 端口验证：未登录页面、合成账号登录成功、空账户提示、退出成功、错误密码提示及密码框清空。已查看窄屏实际显示；未执行完整桌面断点、无障碍审计或所有异常状态浏览器测试。网络失败和限速状态已有前端处理，但未在本轮浏览器单独触发验证。

临时 ui-preview 用户及会话已清理，未留下测试账号。真实管理员可通过上一小步的隐藏输入命令自行创建。开发预览保留运行于 http://127.0.0.1:8082 ，运行日志及 PID 位于忽略的 .runtime/login-preview.log 和 login-preview.pid，进程使用独立本地应用数据库账号。该进程不属于生产守护服务，关闭或重启后需按 README 重新启动并开启认证配置。

## 边界与下一步

已确认的排序规则、ID 校验、返回契约、迭代兼容、测试隔离等问题继续按用户要求后续逐步解决，本步未混入修复。账户列表只是当前用户范围预览，不是报表首页；没有权限管理或业务报表页面。后续可建立首个关键词报表的合成数据接口，再分步接页面。

回退本次代码提交即可移除静态页面，不涉及数据迁移；线上服务器与旧系统没有变化。
