# S1-07：本机可追溯确认入库

2026-11-10。新增本机维护命令 plan/apply/status。仅在隔离测试库执行合成导入；运行库只升级 0008 元数据结构，没有导入真实或演示日报。

## 流程

先完成文件预览及数据库只读对比，独立核实金额来源、账户映射和快照范围。随后生成计划，查看新增/变化/未变化统计；明确提供计划 ID 与完整确认指纹才会执行。

```powershell
$env:PYTHONPATH='src'
uv run --locked python -m dashboard.import_execute plan --input 路径.json --mapping 映射.json --amount-reference "已独立核实的来源证据编号"
uv run --locked python -m dashboard.import_execute apply --input 路径.json --mapping 映射.json --plan-id 计划ID --confirm 计划返回的确认指纹
uv run --locked python -m dashboard.import_execute status --plan-id 计划ID
```

使用受限运行配置注入本机应用数据库连接；CLI 仅允许 127.0.0.1:13306/onetitle_v2_local。此工具属于具备本机配置访问权的维护者，不提供业务用户 HTTP 写入权限，不是生产导入入口。

金额依据是维护者确认前提，不是程序已经验证真实来源。程序只保存依据摘要，调用者需在受控位置保存对应证据。不得把任意字符串当作来源已核实；旧浮点核对候选仍被拒绝正式写入。账户改名歧义继续阻止计划，不擅自决定合并。

## 绑定和一致性

- 单次读取文件内容后解析并计算摘要，避免解析与指纹用两次不同文件读取。摘要针对去 UTF-8 BOM 后的文本（含空白变化），不是原始二进制文件字节；另绑定映射、规范候选、数据库状态与来源依据摘要。
- 计划一小时有效，0008 表只存指纹、影响统计、状态、处理键数、时间及本地维护来源。系统用户名截取前一百字符，仅供本机来源说明，不代表经网页登录认证的操作者；当前记录不具备不可篡改保证。
- 创建计划只写元数据，不写正式日报。执行时锁定计划、目标账户及其现有日报范围，重新读取当前状态后比对。相同账户的其它日期/指标或归属变化也会保守要求重新预览。
- 当前只支持最多一千候选、目标账户合计最多一万条现有日报，用于本机小批验证；超过上限拒绝，不作为生产大批导入方案。未进行并发锁竞争或性能压力验收。
- 日报和 applied 状态同事务提交，失败全部回滚。成功计划再次显式执行只返回原结果，不重复覆盖；重试仍须文件/映射指纹匹配。已成功计划的状态查询不重新宣称当前日报仍与当时相同。
- 提交网络异常可能导致结果未知，先用 status 按计划 ID 核对；仅凭 CLI 非零不能断言数据库未提交。过期或失效计划不自动删除，保留追溯。

## 界面与后续

当前是本机 CLI 流程，页面仍为合成报表。没有网页上传、业务角色授权导入、生产采集、失败事件独立审计或数据回滚界面。后续应先接通正式事实的只读报表并明确展示来源，再按业务需求接文件导入 UI；不能将本机维护权限当成网页导入权限。

0008 降级只删除计划追溯，不撤销已导入数据；确认入库没有自动数据撤销。真实使用前必须落实备份恢复及数据更正流程。之前登记的认证/权限问题仍在待修清单。
