# S1-10 关键词每日明细页面

正式报表中的词文本改为明细按钮，打开原生 dialog，显示当天消耗、展现、点击、
综合线索和线索成本。沿用服务端已应用的账户与日期筛选，未提交的表单修改
不会改变明细上下文。合成来源不显示每日入口，不伪装为正式来源。

文本使用 textContent，保留完整词且不执行 HTML。弹窗支持 Escape 和关闭按钮，
浏览器原生限制焦点；关闭、列表重查、会话结束均取消明细请求并递增序号，
防止过期响应重新显示数据。加载、无数据、超时、403、422、401 独立处理；
可恢复错误支持重试，缺失日报日期不补零，最多 366 天由接口校验。

桌面与 390px 窄屏 Edge 合成接口验证通过：成功展示、筛选快照、HTML 文本安全、
Escape 关闭、失败重试、空态、关闭后慢响应丢弃及窄屏弹窗尺寸，无页面脚本
异常。截图留在忽略的本地 UI 验证目录；本次未连接真实账户或运行库。
JavaScript 语法及 Prettier 检查通过；后端未修改，沿用上一轮接口与权限测试。

静态资源版本更新为 daily-detail-1。当前预览若仍由旧进程运行需正常重启后刷新，
不擅自终止未知进程。回退本提交即可恢复原列表。运行库没有日报时仍为空态，
不自动插入演示数据。两份内部数据库文档和本地计划改动不随本次提交上传。

服务器供他人访问已记录为交付目标；生产配置、HTTPS、安全 Cookie、独立服务
及新旧隔离仍需单独准备和验证，本步不执行服务器变更。
