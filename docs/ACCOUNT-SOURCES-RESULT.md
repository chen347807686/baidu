# 外部账户映射基础

## 范围

0011 新增 account_sources 空表，纳入共享 schema 和结构漂移检查。
来源命名空间与稳定账户 ID 联合唯一，使用二进制排序规则；同名账户不合并。
映射指向内部 access_accounts，具有来源名称、渠道、启用状态、映射版本、
创建/更新时间及可空凭据引用。没有 API token 存储字段。

数据库限制合法渠道、正版本、非空来源身份和布尔状态。账户外键不级联删除。
本步没有管理接口或自动创建映射，现有权限与日报读写保持原样。
降级只允许空表，有映射时阻断自动删除；该保护仅用于停写维护窗口，
不能保证与并发写入竞态安全，正式回退必须先停止映射写入并备份核对。

## 验证与状态

隔离 MySQL 验证唯一身份、同名与大小写不同 ID、不同来源相同 ID、
外键、状态、版本、空身份拒绝、非空降级保护与空表回退再升级。
共享结构漂移和应用账号权限同步验证。完整 97 项测试通过，
Ruff、格式检查、mypy strict 通过。
