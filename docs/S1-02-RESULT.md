## 本步交付

- 白色主背景、浅蓝辅助，登录后展开工作区；日期、可见账户、关键词包含筛选；消耗/点击/综合线索/线索成本汇总；关键词表格、字段排序和分页。
- 页面明确显示“合成数据验证”。汇总按整个筛选范围展示，金额保留后端十进制字符串；表格窄屏独立横向滚动。
- 查询中清空旧表与汇总，禁用分页；错误显示重试，账户撤权提示刷新范围；401 清除报表并返回登录。
- 新请求取消旧请求并校验序号；退出清空列表和汇总。登录控件与报表控件各自管理状态，避免互相覆盖禁用状态。输出均为文本，不注入接口 HTML。
- 新增脚本与样式有中文用途/流程说明，前端通过 Prettier 格式化。

10 项相关 Python 测试通过（HTTP 认证/静态资源、报表、基础服务）；JavaScript 语法、Ruff lint、mypy strict、前端格式检查通过。TestClient 既有弃用提示仍在。未运行依赖空凭据库的管理员初始化测试，未宣称整套测试通过。
