## 使用

先运行 scripts/local_mysql.py migrate。项目根目录设置 PYTHONPATH=src，然后在支持隐藏输入的本机终端执行：

```powershell
uv run --locked python -m dashboard.manage bootstrap --username 自选登录名
uv run --locked python -m dashboard.manage reset --username 已有登录名
```

每次提示输入密码两次；密码不通过命令行参数传入，不输出或写入日志。不支持隐藏输入的终端拒绝继续。本工具读取受限 .runtime/mysql/local.json 的本机 root 凭据，仅操作 127.0.0.1:13306 的 onetitle_v2_local；执行者需有本机受限文件访问权。该权限等同本地维护能力，不向网页用户开放。

bootstrap 只在尚无登录凭据时允许创建首个管理员；不提供默认密码。reset 重置指定账号密码并删除其所有设备会话，不改变角色、归属或启用状态。当前没有执行实际管理员创建，管理员信息由使用者自行输入。

命令以 MySQL 命名锁串行执行；每次维护使用独立事务，同步写入动作、目标用户、当前系统用户名称和 UTC 时间。系统用户名称仅用于来源说明，不代表外部认证的操作者身份。

登录增加凭据行锁，与密码重置串行：重置前成功的登录会话会被删除，重置后旧密码不能通过校验。SQL 操作失败时事务回滚，命令返回非零退出码且不打印底层异常参数。
